# Tech Troubleshooter
A three-page classroom workshop by Fahad Baloch.

## Publish on GitHub Pages
Upload the files in this folder to the root of a GitHub repository.
Enable GitHub Pages from the main branch, / (root).
Keep index.html, problems.html, practice.html, style.css, problems.js, and quiz.js together.
No installation, build step, account database, or separate server is needed.

## Present
Start Here explains a four-step troubleshooting method.
Common Problems provides Wi-Fi, slow-computer, and printer guides with interactive checklists.
Test Your Skills has six four-choice practice questions with explanations, plus a Kahoot join link.
Host Kahoot separately in your own account and display the live PIN.
kahoot-questions.txt contains a prepared set to add manually. No Kahoot quiz was created in your account.

Checklist progress is stored only in the current browser when local storage is available.
The illustrated status displays are teaching examples, not live device diagnostics.
Official Microsoft guides are linked on the Common Problems page.
