CASE 02

A slow computer.
A clearer starting point.

A slow computer can have several causes: busy apps, limited free storage, background activity, or hardware limits. Slowness alone does not identify the cause.

The first question

KNOW WHEN TO ASK FOR HELP

If it stays slow, report the affected apps, resource usage, and recent changes to IT. Avoid random “speed booster” downloads.

THINK IT THROUGH

A browser with many tabs is slow, but other apps respond normally. What is a sensible first step?

Save anything important, close unneeded tabs, and test the browser again. Avoid jumping straight to replacing the computer.

KNOW WHEN TO ASK FOR HELP

If printing still fails, note the printer name, error message, and whether other people can print. Send these details to IT.

THINK IT THROUGH

You clicked Print, but a PDF file appeared instead of a paper copy. What should you check?

Check the selected printer. A PDF destination creates a file rather than sending the job to the physical printer.
